Studio Video AI — Gemini Omni

Generate video benar-benar jadi pakai Gemini Omni 1.1 Flash lewat API key Gemini kamu sendiri. Ada setting durasi 3–10 detik, bisa prompt saja atau pakai referensi video / gambar. Seedance jalan lewat BytePlus (key terpisah), Sora sudah ditutup.

1 API Key

Generate video memakai API key Gemini milikmu. Key hanya hidup di memori tab ini selama halaman terbuka — tidak disimpan, tidak dikirim ke mana pun selain Google saat kamu menekan Generate.

Belum ada key Belum punya? Buat gratis di Google AI Studio — tapi Gemini Omni hanya jalan di tier berbayar.

Seedance adalah model ByteDance — API key Gemini tidak bisa dipakai untuknya. Tanpa key BytePlus, tombol Seedance membuat payload permintaan yang bisa kamu salin dan kirim dari tempat lain.

2 Pilih Model

Hanya model yang masih hidup yang bisa dipilih untuk generate.

3 Cara Buat, Prompt & Durasi

Pilih cara buatnya: prompt saja, atau pakai referensi. Lalu atur durasi detiknya — Gemini Omni menghasilkan klip 3–10 detik per generate.

Paling bagus klip pendek. Menurut dokumentasi Omni, referensi video yang paling andal diproses adalah potongan sampai ±3 detik (file sampai 10 detik tetap bisa dicoba — audionya diabaikan). File dikirim inline sebagai base64 ke Google, jadi file kecil lebih cepat dan tidak kena batas ±4 MB.

Gambar dipakai sebagai frame awal / acuan karakter & gaya. File dikirim inline sebagai base64 ke Google.

    Soal Model-Model Ini
    
            
    
              
    
                Veo 3.1 → Gemini Omni 1.1 Flash
                
    Model Veo 3.1 Preview veo-3.1-generate-preview dimatikan Google pada 22 Oktober 2026, jadi generate lama selalu kena 404. Halaman ini sekarang memakai penggantinya, gemini-omni-1.1-flash, lewat Interactions API. Prompt negatif dan pilihan tanpa audio dituliskan ke dalam prompt, karena Omni tidak punya parameter terpisah untuk itu.
    
              
    
              
    
                Durasi & referensi di Omni
                
    Durasi Omni dibatasi 3–10 detik per klip. Karena API tidak punya kolom durasi terpisah, slider di halaman ini menuliskan detik pilihanmu ke dalam prompt. Referensi dikirim sebagai input media di Interactions API: gambar memakai task image_to_video, video memakai reference_to_video atau edit. Referensi video paling andal ±3 detik dan audionya diabaikan; media inline dibatasi ±4 MB.
    
              
    
              
    
                Seedance bukan punya Google
                
    Seedance 2.5 dan 2.0 adalah model ByteDance dan hanya bisa diakses lewat BytePlus ModelArk dengan API key BytePlus — API key Gemini apa pun tidak akan diterima di sana.
    
              
    
              
    
                Sora sudah berakhir
                
    Aplikasi Sora ditutup 26 April 2026, API Sora 2 dimatikan 24 September 2026, dan OpenAI tidak menyediakan pengganti satu-satu — karena itu tidak ada tombol generate untuk Sora di sini.
    
              
    
              
    
                Jammable itu suara, bukan video
                
    Jammable adalah platform AI song cover: kamu mengunggah vokal dan memilih model suara. Untuk memakainya, buka jammable.com — API-nya hanya tersedia di paket Power berbayar.
    
              
    
              
    
                Semua generate berbayar
                
    Gemini Omni 1.1 Flash dan Seedance sama-sama berbayar per video/detik ke akun provider masing-masing. Halaman ini tidak menyediakan kuota atau key bersama.
